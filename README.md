- **Dashboard (apresentação, uso público):** https://dashboardbimbofastlog2026completo1.vercel.app
- **Painel da Analista de RH (importação de dados):** https://dashboardbimbofastlog2026completo1.vercel.app/admin.html

## Sobre o painel da analista

Página separada do dashboard, com login próprio. É onde a analista de RH importa as planilhas (Espelho de Ponto, Controle de Presença Diária, Controle de Contratações) que atualizam o dashboard automaticamente.

Esse link não aparece em nenhum lugar do dashboard — evite divulgar fora da equipe responsável pela atualização dos dados.
